Things I've built

TuneTalk

An NLP-based chatbot that offers empathetic emotional support and recommends music matching the user's mood. Published as a research paper at ICSET 2026.

  • Emotion detection using a fine-tuned RoBERTa model (65.8% accuracy, 0.6558 macro F1 on 2,380 test samples)
  • Empathetic response retrieval using Sentence-BERT and cosine similarity
  • Mood-based recommendation of five songs from the Spotify dataset
  • Flask REST API connected to a React web interface

Python Flask RoBERTa Sentence-BERT React Vite
